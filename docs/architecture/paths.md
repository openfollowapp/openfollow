# Paths

Covers `paths/`, the pathfinder lock and the path editor. The rules that apply everywhere are in [CLAUDE.md](../../CLAUDE.md).

Experimental. A path is a list of PSN-absolute X/Y/Z points a marker can be locked onto and walked along.

- **`paths/geometry.py`**: `build_curve` turns a path into a `PathCurve`, straight between its points with each interior corner (every corner when closed) rounded by an arc of that point's radius. An arc takes at most half of either neighbouring segment, so a radius too big for the corner shrinks. Up to a 120° turn the arc keeps the full radius; past it the arc tightens the sharper the turn (it meets each segment `3 × radius / tan(turn / 2)` from the point), closing on the point as the turn reaches straight back, so an out-and-back path reaches its far point and a turn close to straight back draws nearly the same curve as one exactly straight back, which is sharp at the point. The curve is a dense polyline whose chords stay within 1 mm of the arcs, addressed by arc length `s`: `point`, `tangent`, `directions` (arriving and leaving, which differ on a sharp corner, so a walk can leave one by either segment), `nearest`, `advance` (an open curve reports which end stopped it), `offset` (the shorter way round a loop). Z follows linearly along the straight parts and through each arc.
- **`paths/network.py`**: `PathNetwork` holds the active paths' curves and their junctions. Two paths meet where they cross in plan at the same height (`JUNCTION_HEIGHT_M`, 0.1 m), and a path whose end lies within `JUNCTION_REACH_M` (0.1 m) of another joins it there. An arc passes its point by, so before junctions are found `extend_to_corners` carries on an open end that lies within reach of another path's corner point (`PathCurve.corners`: the inner points of an open path, every point of a closed one) but touches no other curve: the end runs on straight, its height changing linearly, to where that path's curve passes nearest the point (the arc's middle, at the same height), and joins there by touch, so a marker crosses over without a jump. The old end becomes a sharp inner point. `PathNetwork.curves` are the carried-on curves, which is what is walked, projected onto and drawn. Paths that only turn at the same point join only where their curves meet. A path crossing itself, or a loop coming close without crossing, makes no junction. `find_junctions` compares two paths segment by segment only where the bounding boxes of runs of `_BOX_SEGMENTS` segments come within reach of each other, `_BOX_PAIRS_PER_PASS` pairs of boxes at a time so a dense pair takes bounded memory, and looks for a repeat junction only among those already kept within a few centimetres of it. `walk` moves a locked marker by the part of the push that points along its path; at a junction it takes the direction closest to the push, leaving its own path only when the other is more than `_SWITCH_MARGIN_RAD` (15°) closer. A marker within `_CAPTURE_M` of a junction can steer into it from standing. Pushing past an open end stops there, or reports `released` when that end releases. `nearest` projects a position onto the nearest place over every path or among some, and `connected` names the paths reachable from one through junctions, so a position can be projected onto the paths a locked marker can reach.
- **Names** are what OSC addresses: `[A-Za-z0-9._-]`, at most 32, unique ignoring case, and never dots alone, which a URL resolves away. `PathsConfig.__post_init__` reduces a bad name and renames a clash (`-2`, `-3`) rather than dropping geometry; caps are `MAX_PATHS` (32) and `MAX_PATH_POINTS` (100).
- **Active is per station.** `PathsConfig.replace_paths` takes another source's paths but keeps this station's Active flag per name (a new name arrives inactive); every route that writes paths from outside uses it: the `paths` section of the JSON API and section broadcast, import and Broadcast All (which carry paths, unlike zones), and the `paths` template type. `show_paths` is device-local in the section (`_DEVICE_LOCAL_FIELDS_BY_SECTION`). A `paths` value that is not a list leaves the paths alone.
- **Turning experimental features off deactivates every path** (`/settings/experimental`), as it turns detection off.
