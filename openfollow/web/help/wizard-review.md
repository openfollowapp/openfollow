# Review

Apply saves the camera, the lens and the points. In Simple mode it also saves the rectangle as the grid. The green grid is the one the Operator Screen will draw.

Every point is saved, so **Apply & Finish** stays off while a point is not complete, such as a known point without a value or a triangulated point without a pin. Review names each such point and what it needs; **Points** and **Pinned** count what Apply saves.
