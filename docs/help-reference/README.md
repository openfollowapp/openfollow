# Help reference

The full-length text behind each help drawer (`openfollow/web/help/<id>.md`),
one file per drawer with the same name. The drawers keep only what an operator
needs beside the control; these files keep the detail for the website
documentation.

They are not served by the station and are not checked by the test suite, so a
change to a control may leave them behind. Update the matching file here when
a drawer change drops or rewrites something the full documentation still needs.
