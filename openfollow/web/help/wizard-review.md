# Review

**Save and finish** saves the camera, the lens and the points. In Simple mode it also saves the rectangle as the grid. The green grid is the one the Operator Screen will draw.

Every point is saved, so **Save and finish** stays off while a point is not complete, such as a known point without a value or a distance point without a pin. Review names each of these points and what it needs. **Points** and **Pinned** count what **Save and finish** saves.
